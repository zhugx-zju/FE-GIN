# GRF (Gaussian Random Field) Data Generation

This directory contains scripts for generating datasets with GRF-based modulus fields using RBF (Radial Basis Function) kernels.

## Overview

The GRF generation implements the methodology described in the paper framework:
- **GRF prior**: `g(x) ~ GP(0, k_RBF(x,x'))`
- **RBF kernel**: `k(x,x') = exp(-||x-x'||²/(2ℓ²))`
- **Positive modulus mapping**: `E(x) = E₀ exp(σ_g g(x))`

## Files

### Core Functions
- `GRF_Generate.m` - Generate GRF samples with RBF kernel

## Parameters

### GRF Parameters
- `E_max`: Maximum modulus value (typical: 8.0)
- `sigma_g`: GRF variability parameter (typical: 1.0)
  - Controls field variation intensity
  - Larger values → more variation
  - Uses tanh transformation to ensure values stay in range
- `ell`: Correlation length (fixed: 2.5)
  - Controls spatial smoothness
  - Larger ℓ → smoother fields
  - Normalized by domain size: ℓ/L ≈ 0.28

### Mesh Parameters
- `geoL, geoH`: Domain size (default: 9 x 9)
- `nelL, nelH`: Number of elements (default: 40 x 40)
- `nodesx, nodesy`: Number of nodes (default: 41 x 41)

### Material Parameters
- `nu`: Poisson's ratio (default: 0.3)

### Loading Parameters
- `F_tot`: Total force (default: 0.01)

## Implementation Details

### IGFE Consistency

The GRF implementation maintains consistency with the IGFE (Isoparametric Galerkin Finite Element) approach:

1. **Nodal definition**: Modulus E defined at nodes
2. **Element extraction**: Extract 4 nodal values per Q4 element
3. **Gauss point interpolation**: Use shape functions to interpolate to Gauss points
4. **Integration**: Standard Gauss quadrature

This is implemented in `getFGMBD.m` case 'grf':
```matlab
case 'grf'
    Efield = materialInfo.E_field;  % Nodal field
    Efield_vec = Efield';
    Efield_vec = Efield_vec(:);
    eleNodsID = meshInfo.eleNodsID;
    GEle = Efield_vec(eleNodsID);  % [nEle x 4]
```

### Value Range Control

The modulus values are guaranteed to be in [E_min, E_max] using:
1. Generate GRF: `g ~ GP(0, K_RBF)`
2. Apply tanh transformation: `g_norm = tanh(sigma_g * g)` → [-1, 1]
3. Shift to [0, 1]: `g_norm = (g_norm + 1) / 2`
4. Scale to [E_min, E_max]: `E = E_min + (E_max - E_min) * g_norm`

This ensures all generated values are strictly within the specified range.

### Computational Efficiency

For large datasets:
- GRF generation: O(n³) due to Cholesky decomposition
- For 41x41 grid: ~1681 points, manageable
- Progress printed every 100 samples
- Consider parallel processing for very large datasets

### Numerical Stability

- Small jitter (1e-6) added to covariance matrix for Cholesky stability
- Ensures positive definiteness

## Troubleshooting

### Memory Issues
If running out of memory:
- Reduce `num` (generate in batches)
- Use coarser mesh (reduce nodesx, nodesy)

### Slow Generation
- GRF generation is O(n³), expected for fine grids
- Consider reducing grid resolution for testing
- Use `test_grf.m` with small `num` first

### Cholesky Decomposition Fails
- Increase jitter in `GRF_Generate.m` (line with `1e-6 * eye`)
- Check correlation length is reasonable (not too small)
